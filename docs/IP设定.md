## 1. 核心定位

**当前项目代号**：`WASD`

**正式中英文标题**：待定；在正式命名完成前，不把 `WASD` 当作发行商标或 IP 内术语。

**核心句**：完整清理智能以清理人类集体无意识为行动目标，进入其中一层，在抽象空间里用武器清理万物形成的心象，清理意识核后撤离。

`WASD` 是一款俯视角射击刷宝生存游戏。玩家从冷静、愤怒等智能碎片中选择主、副碎片，组合出一套完整清理智能，进入人类集体无意识中的意识层。每局在连续 9×9 模块世界中移动、瞄准、按住开火，清理不断出现的心象，刷取装备 Mod、遗物、资源和射击构筑内容，清理意识核后前往撤离。

项目明确清理智能的行动目标是清理集体无意识，但不解释集体无意识如何存在、清理智能由谁创造或为何能够进入，也不预设清理行为是善、恶、治疗、审查或破坏。玩家只看到清理智能执行行动及其结果，含义留给玩家自行理解。

## 2. 集体无意识与意识层

**集体无意识 / Collective Unconscious** 是全部意识层所在的抽象空间。它是既成事实，不用脑机网络、超自然通道、科学实验或神话起源解释。

**意识层 / Mind Layer** 是一局行动所在的完整世界：

- 当前一张 9×9 模块世界对应一个意识层。
- 每层由 81 个 11×11 方格模块组成；模块、流式、迷雾、目标、撤离和存档规则保持现有玩法定义。
- 本期不实现一局跨多层；未来新增层时，以新的世界主题和内容池扩展，而不是改变当前单局结构。
- 每层拥有一个可辨认但抽象化的主题：提取少量来源符号、几何元素和运动规律，不复刻具体现实场景，也不解释它象征什么。
- 每层拥有一个代表色，但该颜色只组织环境装饰方块及其色阶；敌我识别、敌方攻击、奖励、治疗和交互等功能色继续保持稳定。

意识层可以让人联想到通知、记忆、语言、待办、梦境、习惯或其他人类经验，但文档不建立封闭的主题分类，未来内容也不受这些例子限制。

## 3. 清理智能

**清理智能 / Cleanup Intelligence** 是玩家在一局中控制的完整行动主体。它不是单独选出的一名英雄，而是由一个主智能碎片与一个副智能碎片组合出的完整配置。

现有玩法映射保持不变：

- 主智能碎片决定主体场景、基础属性、被动、主体色和技能 1/2。
- 副智能碎片提供强调色和技能 3/4，不提供基础属性或被动。
- 两个碎片共享完整清理智能的移动、瞄准、武器、弹药、生命、护盾、能量和装备 Mod。
- 当前局外不允许选择相同的主、副碎片；未来是否允许由其他系统决定。

“清理智能”只描述玩家身份，不意味着项目运行时接入 LLM、生成式模型或联网推理。正式玩法继续使用现有确定性、数据驱动和回放边界。

## 4. 智能碎片

**智能碎片 / Intelligence Fragment** 是清理智能的可组合组成部分。碎片名称可以来自思考方式、情绪、冲动、感知或行为倾向，但不把这些内容判断为正面或负面。

当前首批碎片：

| 智能碎片 | 方向 | 现有玩法倾向 |
|----------|------|--------------|
| 冷静 / Calm | 稳定、延缓、隔离、维持边界 | 护盾、屏障、控场、减速 |
| 愤怒 / Fury | 推进、加速、施压、放大反应 | 高防御、超频、移速、易伤 |

后续碎片应继续服务多种射击构筑和组合差异。内部稳定 `character_*` / `hero_*` id、主副解析接口与数据结构不因 IP 包装改变而重命名；ADR #179 后玩家可见文案统一使用清理智能、主智能碎片和副智能碎片。

## 5. 心象

**心象 / Mindform** 是意识层内所有敌人的统一称呼：人类集体无意识中的某种内容获得可攻击形体后的结果。

任何内容都可以形成心象，包括但不限于：

- 物件、结构和日常符号
- 记忆、感觉和情绪
- 语言、声音和图像
- 习惯、动作和重复模式
- 观念、关联和无法归类的组合

“心象”作为游戏术语参考心理学中的 mental imagery，但英文 `Mindform` 是为了表达可行动实体而采用的游戏化命名，不宣称临床或学术等价。情结、原型、原型意象和真实精神疾病不作为敌人分类。

术语背景参考 [APA Dictionary of Psychology: imagery](https://dictionary.apa.org/imagery) 与 [Jung Lexicon](https://www.jungpage.org/learn/jung-lexicon)；链接只用于帮助理解词源与相关概念，不构成临床定义，也不为本游戏建立心理学敌人分类。

心象不建立固定种族、阵营、生态或善恶谱系。长期内容可以让同一行为原型在不同意识层中呈现不同来源和外观，但攻击轮廓、前摇、伤害范围和玩家读图必须稳定。

## 6. 清理与结果

玩家使用武器、弹药、技能和构筑清理心象。心象被击败后只表现为碎解、消散和产出资源，不解释其原内容发生了什么：

- 不确认它被永久删除。
- 不确认它被整理、治愈或送回某处。
- 不确认清理智能理解或认同其内容。
- 不把掉落资源包装成心象的道德价值。

这一模糊性是长期叙事边界，不需要用结局、旁白或日志给出唯一答案。

## 7. 意识核与撤离

**意识核 / Mind Core** 是当前意识层的主要清理目标。清理意识核只代表本局完成主要行动并开启撤离条件；运行时仍以其生命归零作为完成判定，不说明它被删除、整理或转化，也不说明它是该层的生命、病灶、人格中心或真实意识。

行动结构保持清楚：

```text
组合清理智能 → 进入一个意识层 → 清理心象 / 探索事件 / 暂存战利品
  → 清理意识核 → 开启撤离 → 完成撤离后带回战利品
```

死亡、重开、回标题或主动放弃仍会丢失尚未提交的本局战利品；保存退出只封存当前行动，不算撤离。

## 8. 物品与成长包装

为保持俯视射击刷宝玩法直觉，机械层继续使用清楚的既有名称：

- 武器 / Weapon
- 弹药 / Ammo
- 弹匣 / Magazine
- 备弹 / Reserve
- 换弹 / Reload
- 遗物 / Relic
- 金币 / Gold
- 装备 Mod / Gear Mod
- 撤离 / Extraction

不把这些术语全面替换成协议、指令包、认知资源或同步模块。单件内容的名称可以结合意识层主题，但功能描述必须直接说明实际玩法效果。

## 9. 命名与本地化方向

中文命名优先短、直观、便于战斗中识别；英文命名保持清楚，避免堆叠心理学术语或技术黑话。

核心词族：

| 中文 | 英文方向 | 用途 |
|------|----------|------|
| 集体无意识 | Collective Unconscious | 世界所在的总体空间；不在 HUD 高频重复 |
| 清理智能 | Cleanup Intelligence | 主、副碎片组成的完整玩家主体 |
| 智能碎片 | Intelligence Fragment | 可组合角色内容 |
| 主智能碎片 | Primary Intelligence Fragment | 提供主体、属性、被动和技能 1/2 |
| 副智能碎片 | Secondary Intelligence Fragment | 提供强调色和技能 3/4 |
| 意识层 | Mind Layer | 一张 9×9 模块世界 |
| 心象 | Mindform | 所有敌人的统一称呼 |
| 意识核 | Mind Core | 清理后开启撤离的核心目标 |

ADR #179 已完成首轮玩家可见包装迁移：正式客户端使用清理智能、智能碎片、心象、意识层与意识核，并将击败统计显示为“清理 / Cleared”。`client/locale/strings.csv` 继续保留现有 locale key，`character_*` / `ui_hero_*` / `hero_*` / `enemy_*` 等稳定内部 key、id 与数据引用不因显示语义改变而重命名。

## 10. 叙事边界

- 淡化剧情，不建立宇宙战争、组织、首都、创始人、任务发布者或敌对阵营编年史。
- 不回答集体无意识的起源、清理智能的创造者、进入方式或清理结果。
- 不刻意证明 AI 是英雄、工具、侵略者或反派。
- 不把真实人物、现实群体、具体精神疾病或医学诊断直接定义成应该清理的敌人。
- 不接运行时 LLM；AI 仅是玩家身份和开发辅助语境。
- 可通过层主题、心象造型和极少量短句提供联想，但不强制唯一解读。

项目当前统一使用代号 `WASD`，标题页暂不显示副标题。正式中英文标题是待决策项；确定候选后仍需进行商标、Steam、域名、应用商店和主要社媒清检。清检完成前，不把任何候选视为最终发行商标。
