# IP 美术风格

> **AI 修改说明**：修改本文档前先读 `docs/AI协作/文档维护指南.md`。
> 本文档是项目代号 `WASD` 的 IP 美术风格、意识层主题色、心象视觉语言、敌我与功能色、资产 brief 规则权威；改美术主口径、层主题、敌我色、兴趣点色彩或资产 brief 规则时，必须同步 `docs/IP设定.md`、`docs/游戏设计文档.md`、`docs/AI导航.md`、`docs/术语表.md`、`docs/决策记录.md`、`docs/AI记忆/项目记忆.md` 与 `docs/AI记忆/current_state.json`。

## 1. 核心美术句

`WASD` 的视觉方向是：**用抽象、简洁、来源可辨的元素构成意识层；每层由一个代表色组织环境装饰，心象与战斗信息保持稳定可读。**

目标读法：

- 第一眼能看清玩家、心象、弹幕、奖励、机关和交互目标。
- 第二眼能读出本层的代表色、来源符号和运动规律。
- 玩家可以联想到现实物件、记忆、语言、习惯或其他内容，但画面不复刻具体现实场景，也不解释唯一象征。
- 不依赖剧情文本说明当前画面的含义。

## 2. 抽象化原则

每个意识层从一个可理解来源中提取少量元素：

- 基础形状：方块、圆、线、框、角标、重复纹样。
- 来源符号：例如通知点、待办框、文字片段、日历格、窗口边框或其他可辨特征。
- 运动规律：聚合、重复、回环、错位、脉冲、追逐、扩散。
- 空间规律：密度、留白、方向、层叠、断裂和节奏。

提取后必须抽象化：

- 不直接复刻手机桌面、办公室、卧室、社交软件或真实品牌界面。
- 不把一层做成具象叙事场景或可逐物解释的布景。
- 不要求每个元素都对应唯一含义。
- 不用精神疾病、医学诊断、真实人物或现实群体做视觉敌人分类。

## 3. 意识层代表色

每个意识层选择一个**代表色**，但项目不建立固定的全局环境主色板。

代表色只用于：

- 环境装饰方块
- 非功能性背景纹样
- 边缘装饰与低优先级层内结构
- 同一层装饰的深浅、明度和饱和度派生色阶

代表色不覆盖：

- 玩家与智能碎片配色
- 各心象原型的稳定敌人色
- 玩家与敌方弹幕的识别色
- 伤害预警、危险边界和攻击前摇
- 奖励、治疗、升级、武器、祭坛和其他功能色
- UI、HUD、文本和可交互提示

一张 9×9 模块世界对应一个意识层，因此同一局的环境装饰使用同一代表色家族。本期不定义一局跨层换色，也不新增运行时色板字段；未来实现时另立数据与验证任务。

## 4. 敌我与功能色

敌我颜色和功能色继续保持稳定，不随意识层代表色漂移。当前正式资产与占位场景已有的玩家配色、各心象原型配色、红色敌方远程攻击和现有功能色可以继续使用；本轮不重配正式素材。

稳定规则：

| 归属 | 色彩规则 | 不受层代表色影响的原因 |
|------|----------|------------------------|
| 玩家 / 清理智能 | 由主智能碎片主体色与副智能碎片强调色组合 | 表达玩家构型并维持识别 |
| 心象 | 每个行为原型保留稳定敌人色与轮廓 | 让玩家跨层识别攻击方式 |
| 敌方远程攻击 | 保留稳定警示色 | 优先保证弹幕威胁可读 |
| 玩家弹幕 | 保留玩家侧射击色 | 与敌弹、环境装饰分离 |
| 奖励 / 治疗 / 改造 / 交互 | 保留各自功能色 | 让玩家无需理解层主题即可决策 |
| 危险区 / 前摇 / AOE | 使用稳定警示语言 | 视觉必须对应真实玩法判定 |

如果层代表色与某项功能色接近，优先降低环境装饰饱和度和对比度，不改变功能色。

## 5. 心象视觉语言

心象可以由任意内容形成，但不能因此失去战斗识别。正式设计先确定攻击行为，再决定来源符号和抽象外观。

当前五种行为原型继续通过以下特征区分：

| 行为原型 | 必须保留的读图信息 |
|----------|--------------------|
| 爆裂型 | 可蓄能核心、圆形危险范围、不可逆前摇 |
| 群袭近战型 | 快速逼近、锁向扇区、近距离释放 |
| 伏击冲刺型 | 锁定方向、通道式冲刺范围、持续扫掠 |
| 壁垒冲撞型 | 正面轮廓、重量感、冲撞方向和命中停止 |
| 远程点射型 | 枪口局部蓄光、固定方向点射、稳定敌弹读法 |

同一行为原型在不同意识层中可以更换来源符号和装饰，但必须保留：

- 稳定的俯视轮廓
- 朝向和正面
- 攻击前摇
- 真实伤害范围
- 与其他心象不同的运动节奏
- 不依赖颜色的第二识别通道

## 6. 地图与装饰

意识层仍使用当前矩形 / 方形 2D 网格和俯视判定：

- 环境装饰方块可使用层代表色，但不得遮盖 floor / wall、可走区域和外圈边界。
- 贴地机关、AOE、危险区和交互 footprint 必须对应真实玩法形状，不能被抽象装饰误导。
- 中场战斗区域保持低细节、低对比；高密度符号和运动装饰优先放在边缘或非战斗区域。
- 一层的来源符号应重复形成统一节奏，但不把全部模块做成相同纹理。
- 角色、心象、拾取物、子弹、障碍物和特效不强制使用矩形。

## 7. 地图兴趣点功能色

地图兴趣点继续比环境更像游戏物件。意识层代表色只影响其非功能性装饰，核心功能色保持稳定。

| 兴趣点 | 功能色口径 | 读图目标 |
|--------|------------|----------|
| 宝箱 / 战利箱 | 沿用奖励色 | 奖励 / 值得靠近 |
| 遗物选择 | 沿用稀有 / 构筑色 | 构筑选择 |
| 治疗点 | 沿用恢复色 | 回复 / 安全收益 |
| 升级 / 改造站 | 沿用强化色 | 强化 / 消耗资源 |
| 武器缓存 | 沿用武器与弹药色 | 武器 / 弹药 / 装备 Mod |
| 事件交互物 | 依事件类型保持稳定 | 防御、生存、占点或祭坛 |
| 意识核 | 使用独立目标对比与轮廓 | 核心目标 / 击破后撤离 |
| 撤离区 | 沿用撤离功能色与边界 | 可以离开并提交战利品 |

不要用层代表色取代功能色，也不要让所有可交互物统一发出同一种层色光。

## 8. 子弹与特效读图

- 玩家与敌方弹幕继续使用稳定阵营色，不读取意识层代表色。
- 攻击预警和实际命中范围必须与玩法判定一致。
- 层主题可以影响非功能性碎片、尾迹装饰和消散图案，但不能改变弹丸主体识别。
- 心象死亡表现为抽象碎解、消散和掉落，不说明是删除、修复还是转化。
- 表现层不得修改 Combat、掉落、对象池、回放或其他玩法状态。

## 9. 俯视角落地

本文件只规定 IP 与颜色语言；具体资产继续遵守 GDD §8.2-A 的俯视资产落地规则：

- 贴地范围、机关、AOE、地面符号优先使用矩形 / 方形俯视格或清晰贴地轮廓，并与当前量化矩形地图格对齐。
- 角色、心象、宝箱、拾取物、子弹、障碍物和特效不强制矩形。
- 非地面资产必须声明 `footprint`、`anchor_point`、`orientation_read`、`sort_layer` 和真实碰撞 / 触发形状。
- 不用 3D 运行时、正交投影或菱形地图格模拟斜俯视。

## 10. 资产 Brief 模板

生成或替换非 UI 资产时，至少补齐以下字段：

```text
asset_type:
faction_or_function:
mind_layer_theme:
representative_color:
source_motifs:
abstraction_rule:
functional_color_exceptions:
palette_role:
allowed_colors:
forbidden_colors:
footprint_shape:
anchor_point:
orientation_read:
shadow:
sort_layer:
collision_or_trigger_shape:
readability_note:
```

字段说明：

- `mind_layer_theme`：本资产所属意识层的可辨来源主题。
- `representative_color`：环境装饰使用的单层代表色；非环境资产写 `none`。
- `source_motifs`：被提取的少量符号、形状或运动来源。
- `abstraction_rule`：如何避免复刻具体现实场景。
- `functional_color_exceptions`：必须保持的敌我、弹幕、危险、奖励或交互功能色。

示例：

```text
asset_type: environment_decoration
faction_or_function: mind_layer_background_block
mind_layer_theme: unfinished tasks
representative_color: layer-selected muted violet
source_motifs: checkbox, clipped line, repeated corner mark
abstraction_rule: reduce motifs to rectangles and short strokes; no literal app or calendar UI
functional_color_exceptions: none; decoration must remain below gameplay contrast
palette_role: environment_low_priority
allowed_colors: representative color shades
forbidden_colors: active hazard and interaction colors
footprint_shape: square
anchor_point: cell center
orientation_read: none
shadow: none
sort_layer: ground decoration
collision_or_trigger_shape: none
readability_note: must not obscure floor, wall, projectiles, pickups, or warning shapes
```

## 11. 当前结论

- 一张 9×9 世界是一层意识层。
- 每层有一个可辨但抽象的来源主题，以及只服务环境装饰的代表色。
- 项目不建立固定全局环境色板；敌我颜色、弹幕警示色和交互功能色保持稳定。
- 心象可以来自任何内容，但攻击轮廓、前摇、范围和运动节奏必须先保证读图。
- 当前正式素材、场景颜色、VFX 和数据不在本次设定重构中修改。
- 《破巢者》的钙化活体建筑和虫巢固定色板已由 ADR #178 退役，仅保留在历史记录中。
