# 文档健康检查

> **权威范围**：本文件说明 `tools/docs_health_check.py` 的轻量结构检查；脚本直接扫描仓库，不依赖人工或机器知识索引。

## 命令

```powershell
python tools/test_docs_health_check.py
python tools/docs_health_check.py
```

## 阻塞检查

- 存活 Markdown 的相对链接目标与锚点存在。
- `docs/代码/README.md` 中的 Markdown 模块链接存在。
- 正式脚本的 `# Doc:` 指向存在。
- ADR 编号递增且不重复。
- `current_state.json` 使用 schema v2、精确字段集、大小不超过 8 KiB，且 `active_plan` 存在。
- 四个平台规则适配器存在、不超过 50 行，并引用 `docs/AI协作/项目规则.md`。
- 存活协作文档不重新引用已删除的双索引、项目记忆、会话日志、一次性报告或历史工作包。

脚本不再检查：

- 所有 Markdown 是否登记到机器索引。
- `related_docs` / `related_code` 元数据。
- authority 文件是否与一组相关文档同时改动。
- 每份文档是否带固定“AI 修改说明”。
- ADR 人工追踪矩阵或项目记忆中的 ADR 计数。

## 何时运行

- 新增、删除、重命名文档。
- 修改 Markdown 链接、ADR、current state、平台规则适配器或 `# Doc:`。
- 修改文档健康脚本或回归测试。
- 提交本类变更前。

CI 保持运行 `tools/docs_health_check.py`，并追加 `tools/test_docs_health_check.py`。普通 gameplay 代码修改不需要额外更新文档索引或记忆文件。
