# AI 工具适配指南

> 权威范围：各平台如何加载共同规则、发现项目能力和稳定执行命令。项目行为规则只在 `docs/AI协作/项目规则.md` 维护。

## 通用接入

任何 AI 工具只需按以下顺序加载：

1. `AGENTS.md`
2. `docs/AI协作/项目规则.md`
3. `docs/AI协作/快速开工.md`
4. `docs/AI记忆/current_state.json`
5. `docs/AI导航.md` 的相关任务入口

工具没有自动规则发现时，让它先读上述文件即可。平台入口与规则适配器不得复制或放宽共同规则。

## PowerShell 稳定执行

- 固定文本搜索用 `rg -F`；正则 pattern 使用单引号或变量，全部选项写在 `--` 前。
- PowerShell 路径参数使用 `-LiteralPath`，失败敏感 cmdlet 加 `-ErrorAction Stop`。
- 原生程序执行后立即检查 `$LASTEXITCODE`；`rg` 的 1 仅表示无匹配。
- 不使用 `Invoke-Expression`，不拼接可执行命令字符串，不跨 PowerShell / cmd / Bash 混搭删除或移动操作。
- 一次 shell 调用只承载一个语义操作；允许非零退出码时先显式归一化。
- 仓库修改优先使用结构化 patch；PowerShell 主要用于只读检查和运行验证。

示例：

```powershell
$matches = rg -n -F -- 'target text' docs
$code = $LASTEXITCODE
if ($code -ne 0 -and $code -ne 1) { throw "rg failed: $code" }
```

## 能力降级

- 没有原生 subagent：读取对应 agent 文件，以同一职责在当前对话执行。
- 没有 slash command：读取对应 command 文件并手动执行步骤。
- 没有自动 skill 发现：按任务显式读取相关 `SKILL.md`。
- 没有 Godot GUI：运行适合的 headless / schema / lint；人工视觉、听觉和手感验收继续留给人工。
