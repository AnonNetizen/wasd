# 上下文预算

> 权威范围：任务开始时的最小读取范围。用户最后明确指令始终高于本页和 `current_state.json`。

## 默认预算

所有任务先读：

1. `AGENTS.md`
2. `docs/AI协作/项目规则.md`
3. `docs/AI协作/快速开工.md`
4. `docs/AI记忆/current_state.json`
5. `docs/AI导航.md` 的相关段落

随后只追加目标源码、一个直接权威文档和完成验证所需的脚本。不要默认读取完整 GDD、全部 ADR、全部模块文档或历史 Git。

## 按任务路由

| 任务 | 必读 | 按需追加 |
|---|---|---|
| 私有实现 / 无行为重构 | 目标源码、对应模块文档 | 相邻调用方、测试 |
| 公共 API / 行为 / 边界 | 目标源码、对应模块文档 | 直接消费者 |
| 数据 / schema | 目标数据、`client/data/README.md` | validator、契约 |
| 本地化 | `client/locale/strings.csv`、locale README | 相关 UI |
| 约定字符串 | `docs/词表与契约.md` | 生成器、引用点 |
| 玩法设计 | GDD 相关节、相关 ADR | 模块文档、候选池 |
| 测试政策 / CI | `docs/测试策略.md` 或 `docs/CICD规划.md` | 相关 hook/workflow |
| 文档结构 / 规则 | `文档维护指南.md`、`项目规则.md` | 平台适配器、健康检查 |
| 当前任务 / 决策 | `docs/TODO.md` | `docs/功能建议池.md` |

高频数据任务优先读 `docs/AI协作/任务模板/` 对应模板。

## 何时扩大范围

只有出现以下情况才继续读：

- 公共依赖方向或所有权不清；
- 当前实现与模块文档冲突；
- schema、协议或存档兼容需要历史 ADR；
- 测试失败指向跨模块问题；
- 用户要求审计全局影响。

扩大范围前先说明目的；不得搜索或读取 `draft/` / `DRAFT/`。
