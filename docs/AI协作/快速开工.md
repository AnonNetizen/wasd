# 快速开工

> **权威范围**：本文件是日常新会话的低 token 热路径；完整规则见 `docs/AI协作/项目规则.md`。

## 开工顺序

1. `AGENTS.md` 或当前平台入口。
2. `docs/AI协作/项目规则.md`。
3. `docs/AI记忆/current_state.json`。
4. `docs/AI导航.md` 相关段落。
5. 当前任务的直接权威文档和目标代码。

## 当前边界

- 用户最后明确指令优先；current state、TODO 和历史提交不构成执行授权。
- `draft/` / `DRAFT/` 未经明确授权不得进入。
- 人工验收、L5、真实设备和视觉 / 听觉 / 手感结论只交用户。
- 普通内部重构不更新文档；公共契约变化只更新所属模块文档。
- 不读取或维护项目记忆、会话日志、双知识索引和一次性验证报告；需要历史时使用 Git。
