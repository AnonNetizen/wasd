## 1. 项目快照

- **名称**：wasd
- **作者署名**：中文 `伦敦阿农`；英文 `Anon London`
- **类型**：俯视角射击 Roguelike（手动按住开火 + 模块世界探索 / 战斗 + 局内金币 / Gear Mod 构筑 + 意识核单局终点；玩法判定与显示保持 2D 平面）
- **IP 方向**：ADR #178 已将项目 IP 改为代号 **`WASD`** 下的“集体无意识清理”设定，ADR #179 进一步明确 AI 以清理集体无意识为行动目标，并把玩家文案统一为清理智能、智能碎片、心象、意识层和意识核。完整清理智能由冷静、愤怒等主 / 副碎片组合，进入一张 7×7 意识层，清理万物形成的心象；ADR #188 后意识核清理完成即结束本局，不再撤离。意识层来源、AI 立场和清理结果保持不解释。标题页只显示 `WASD`，正式中英文标题仍待定；威胁九级显示“失序 / Disarray”，击败统计显示“清理 / Cleared”。
- **引擎**：Godot 4.7.1 stable + GDScript（强制类型化；新写 / 修改脚本以 Godot 4.7 官方 GDScript style guide 为基础风格）
- **分辨率与宽高比**：ADR #131 后，正式客户端当前只设计 / 验收固定 16:9 分辨率，默认逻辑画布为 1920×1080；非 16:9 屏幕通过 `canvas_items + keep` 等比缩放并补黑边，不拉伸、不裁切、不扩大玩法视野。其他比例是 P3 优化，未来也按独立固定预设接入，不做连续任意比例适配。
- **当前视角补充**：ADR #124 后当前正式视角为俯视角 2D；地图格、边界、机关和兴趣点 footprint 都使用水平 / 垂直矩形俯视格。ADR #148 的 `Phantom Camera 0.11.0.3` 与 ADR #156 的唯一对局级 Rig 继续有效；ADR #167 让 GLUED 跟随按 aim 平滑偏移，稳定引导与震屏噪声分离。
- **Roguelike 终局补充**：ADR #188 后默认模块世界与 open-warzone 都在意识核 `completes_run` 后立即结束；世界 schema v5 不含撤离字段，Run v19 不含 `pending_loot` 或 `extraction`。结果页显示最终本局 Gear Mod 构筑与非空新解锁。
- **当前状态**：详见 `docs/AI记忆/current_state.json`。ADR #197 已完成架构治理前三阶段，并落地 `EnemySpawnService`、`RunSnapshotCoordinator`、`DataFingerprintBuilder`、`DataReferenceIndexBuilder`、`GearModDropTableValidator`、`LevelProgressionValidator`、`ModuleSlotStateCodec`、`ModifierStack`、`ModuleChunkStreamingController`、GameplayFeedback / Player 表现门面、`ModuleWorldState`、`GameplayDebugFacade`、`EnemyBrain` 与 `ModuleWorldLayout` 十四个渐进提取点；DataLoader 跨文件索引 / 掉落 / 等级曲线校验、ModuleWorld 静态 layout / 动态状态 / chunk cache、角色表现拓扑访问、标准对局 debug API 与敌人纯感知 / Utility 决策均已有独立边界，第二档 lint 已阻断 UI 反向依赖、表现节点直访与默认用户目录测试。Meta v4、Run v19、Replay v9、游戏 v1.18、data hash、map hash、四条 golden 摘要与公开格式不变。
- **正式共享子弹表现**：`bullet_basic` 场景只保存唯一 `BulletSlimeVisual`，其 `EdgeEast / EdgeSouth / EdgeWest / EdgeNorth` 四个持久节点一次生成 64 点向心 Catmull-Rom 边界到 `Polygon2D Body + Line2D Rim`。玩家颜色为 `#DCEAF2 / #F6FBFF`，敌人为 `#E62935 / #FF5963`；configure / restore / reset / release 只换色与缩放，不重建节点。通用 `VfxRibbonTrail` 仍供其他效果使用，VFX baker 不再向子弹场景补回拖尾。
- **视觉效果库 / UI 动效**：ADR #158 / #168 / #176 / #184 / #185 与 GDD §9.24 是统一表现架构权威。正式效果目录为 `client/data/visual_effects.json` schema v3，当前 18 项；内容绑定为 `presentation_profiles.json`。稳定固定枚举进入词表 / 生成契约，effect/profile 主键由 DataLoader 校验，不要求代码常量。正式游戏不登记枪口闪光 effect 或专用池；玩家武器开火 effects 为空但镜头后坐保留，突击枪手前摇 / 逐发 cue 无视觉绑定。正式 Player / Enemy 的 Visual 强制实现 `set_presentation_state(tint, alpha, scale)`，控制器不保留 Body / Outline 旧回退。成品效果必须是可编辑组合 `PackedScene`；AnimationPlayer 默认有 RESET，Tween 只处理动态终值，Curve 为共享节奏资产，Shader preset 只读，程序几何只能作为 Ring / Arc / Wedge / RectTelegraph / RayBurst / ShockRing / RibbonTrail / ShardBurst / SegmentedShell / FocusTicks 等精选复合模板骨架。`RNG.vfx` 与玩法随机流隔离；所有玩家统一使用唯一正式 effect，不存在质量设置、质量变体或降档接口；命中停顿只保留字段，首版不驱动 GameClock。详细运行时、编辑器与建效流程见 `docs/代码/visual_effects.md`，UI 组件见 `docs/代码/ui_effects.md`。

## 2. 核心设计支柱（一眼回忆）

| 支柱 | 一句话 |
|------|-------|
| 数据驱动 | 所有可调数值进 `client/data/`，平表数值优先 CSV、复杂配置优先 JSON；字段说明进 `client/data/README.md`，零代码调参 + 热重载 |
| 双语本地化 | 玩家可见文本进 `client/locale/strings.csv`，当前首批维护 `zh_CN` / `en`；AI 自动补另一语言首版译文，人工最终复核；UI 尺寸以英文 `en` 文案长度作为设计和验收基准 |

## 9. 更新约定（重要）

**触发条件（满足任一即更新）**：ADR 新增 / 修改、编码规则新增 / 修改、待决策项变化、重要文件结构或工具链变化、重要里程碑达成。

**更新动作**（AI 主动执行，无需用户提醒）：
1. 修订本文件第 1~5 节（项目快照 / 决策 / 待决策 / 工具链）以反映长期事实
2. 更新 `docs/AI记忆/current_state.json`（当前阶段、最新 ADR、待决策项、下一步、最近验证）
3. 在第 6 节保留 / 覆盖当日一行摘要（**一行表格条目 + 日志链接**，不展开细节）
4. 在 `会话日志/YYYY-MM-DD.md` 写当日详细摘要（输入/产出/决策/验证）

**节制原则**：只记**结论 + 关键参数 + 文件指针**，不复述完整对话；单次会话总更新量目标 < 1KB；历史细节归入会话日志，短期状态归入 `current_state.json`，长期索引保持精简（< 200 行最佳）。

**自动瘦身（无需用户提醒）**：临近 200 行立即处理；第 6 节保持「日期 + 一句话摘要 + 日志链接」，7 天前按周、30 天前按月聚合；第 3 节只保留编号与一句话；同一位置覆盖更新，`current_state.json` 不承载历史；瘦身无需新 ADR，只在会话日志记一笔。
**不触发条件**（避免噪声）：
- 单纯的代码风格修复 / typo
- 不涉及决策的纯实现工作（在会话日志记一笔即可）

**示例格式**：`| 2026-06-13 | 一句话摘要 | 链接 |`；旧条目按周 / 月聚合即可。

> 维护要求：本文件是 AI 协作的"长期记忆主控"。任何与本约定不一致的更新，应在 `docs/决策记录.md` 中以新 ADR 改写约定，再同步修订本文件。
