# 2026-07-30 会话日志

## 弹药 HUD 用户反馈修正

- 用户截图指出三个问题：HUD 不需要显示总弹药 / 容量，只需显示弹匣内剩余和弹匣外备弹；无弹药时需要提示；`{magazine_size}` 占位符被直接显示。
- 根因是 `GameplayHud` 已向 `ui_hud_ammo` 传入 `{magazine}` / `{reserve}`，但本地化模板仍要求 `{magazine}` / `{magazine_size}`；同时已有 `ui_hud_ammo_reload_hint` 未在空弹匣分支接线。
- 常驻 HUD 现显示“弹匣 {magazine} · 备弹 {reserve}”，删除总弹药 / 容量行；详细面板同步移除总弹药和容量，只保留弹匣、备弹与换弹时间。
- 用户随后指出 HUD 内提示仍不够明显，要求改为角色周围短时文字。最终常驻弹药卡不再显示打空说明；`WeaponSystem` 在正常射击打出最后一发时只请求一次 `ammo_attention_requested`，有备弹显示动态 `reload` 绑定，总弹药耗尽提示再次开火。持续按住不会重复刷字，零弹后每次重新按开火可再次提示。
- `PlayerWorldPrompt` 作为玩家基础场景的头顶子节点跟随角色，短时上浮并按 `GameClock` 淡出；暂停时计时冻结。中英文占位符保持一致，自动测试覆盖角色挂载、文本路由、长按去重、零弹再按与语言切换。
- 该修改只纠正 HUD 展示与提示，不改变弹药数据、掉落、换弹状态机、Run v11 或 Replay v3，不新增 ADR。
- 最终自动验证通过：contracts、data/schema、三档 lint、Godot 版本与导出树、headless boot、input/settings/ammo/L1/runtime/world-event/module-world/save/loading/replay/replay-input/actor/VFX smoke、文档健康、完整 pre-commit 与 `git diff --check`。本地化数据指纹变化后已重录并重跑四条 Replay v3 黄金回放；并行运行时出现的一次 Windows Godot signal 11 在顺序复跑后全部通过，未发现业务回归。
- 视觉可读性仍按 ADR #174 保留为待用户人工验收；AI 只执行自动化验证，不运行性能 probe。

## ADR #178 集体无意识 IP 设定阶段重构

- 用户决定退役《破巢者 / Nestbreakers》当前 IP，正式标题暂缺，统一使用项目代号 `WASD`。
- 新核心设定：完整清理智能由冷静、愤怒等主 / 副智能碎片组合，进入人类集体无意识中的一张 9×9 意识层，清理万物形成的心象，击破意识核后撤离。意识层来源、AI 立场与清理结果保持不解释。
- `docs/IP设定.md` 与 `docs/IP美术风格.md` 已重写；GDD 同步核心摘要、循环、智能碎片包装、模块世界、意识核目标与美术规则。心象参考 mental imagery，但 `Mindform` 是游戏化英文名，不宣称临床等价；具体精神疾病、真实人物和群体不得成为应被清理的对象。
- 每层代表色只用于环境装饰方块及色阶；玩家 / 心象、弹幕警示与交互功能色保持稳定。心象依靠轮廓、运动、前摇和攻击形状区分，不能只靠换色。资产 brief 新增层主题、代表色、来源符号、抽象规则和功能色例外说明，但不建立运行时字段。
- ADR #178 取代 ADR #88 / #111 的当前世界观与美术结论，旧 ADR 原文保留为历史；修改建议新增开放决策 S“正式中英文标题”。术语表、AI 导航、正式项目规划、知识库双索引和项目记忆已同步，旧 IP 词只保留为历史 / 遗留实现检索别名。
