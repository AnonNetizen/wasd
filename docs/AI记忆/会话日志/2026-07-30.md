# 2026-07-30 会话日志

## 弹药 HUD 用户反馈修正

- 用户截图指出三个问题：HUD 不需要显示总弹药 / 容量，只需显示弹匣内剩余和弹匣外备弹；无弹药时需要提示；`{magazine_size}` 占位符被直接显示。
- 根因是 `GameplayHud` 已向 `ui_hud_ammo` 传入 `{magazine}` / `{reserve}`，但本地化模板仍要求 `{magazine}` / `{magazine_size}`；同时已有 `ui_hud_ammo_reload_hint` 未在空弹匣分支接线。
- 常驻 HUD 现显示“弹匣 {magazine} · 备弹 {reserve}”，删除总弹药 / 容量行；详细面板同步移除总弹药和容量，只保留弹匣、备弹与换弹时间。
- 用户随后指出 HUD 内提示仍不够明显，要求改为角色周围短时文字。最终常驻弹药卡不再显示打空说明；`WeaponSystem` 在正常射击打出最后一发时只请求一次 `ammo_attention_requested`，有备弹显示动态 `reload` 绑定，总弹药耗尽提示再次开火。持续按住不会重复刷字，零弹后每次重新按开火可再次提示。
- `PlayerWorldPrompt` 作为玩家基础场景的头顶子节点跟随角色，短时上浮并按 `GameClock` 淡出；暂停时计时冻结。中英文占位符保持一致，自动测试覆盖角色挂载、文本路由、长按去重、零弹再按与语言切换。
- 该修改只纠正 HUD 展示与提示，不改变弹药数据、掉落、换弹状态机、Run v11 或 Replay v3，不新增 ADR。
