## ADR #171 突击枪手点射与常见敌人调整

- 用户要求现有远程怪更贴近弹幕地狱，并把它改成最常见的基础怪。内部 `enemy_spitter`、`enemy_ai_ranged_spitter`、专属对象池和场景路径保持稳定，玩家可见名称改为“突击枪手 / Assault Gunner”。
- `enemy_ai_profiles.json` 升 schema v5。突击枪手在 600 px 射程、280 px 保持距离内，经过 0.65 秒首次攻击延迟后，只在起手视线合法时锁定玩家当时方向并停止移动；显示 0.32 秒直线预警，再以 0.12 秒间隔沿固定方向点射 4 发，整轮完成后冷却 0.95 秒。每弹 18 中性伤害、440 px/s、720 px 射程、5 px 半径、1.8 秒寿命；提交后不追踪、不因失去视线中断，墙体继续挡弹，难度只缩放每弹伤害。
- `Enemy` 新增 `ranged_windup` / `ranged_burst` 状态和 `burst_shots_remaining` 诊断。每轮只发一次 `attack_windup_started`，每弹发一次 `attack_committed`。Run 保持 v8，只增量保存剩余弹数；旧 v8 缺字段按空闲恢复，非法 action、阶段、弹数、方向或计时快照清空攻击并进入一次完整冷却。
- 新增 `presentation_enemy_rifle`，复用直线预警和枪口闪光；`enemy_spitter.tscn` 增加枪管轮廓。共享 `bullet_basic` 根据 `source_team` 切换玩家黄弹与敌方红弹 / 拖尾，并在配置、恢复、释放和复用时完整重置；子弹预热由 24 升至 64，容量保持 192。
- 模式与模块世界完整敌池统一为突击枪手 100、爆猎者 55、群袭者 30、壁垒者 20、伏击者 15，突击枪手从 0 秒解锁并占 100/220（约 45.5%），不设每房保底。开放战区的枪手 wave 从 0 秒起进入所有导演阶段，`spawn_interval=1.35s`、`max_alive=16`；其他波次下调后完整生成率由约 2.0745/s 调为约 2.0732/s，枪手上限占 16/37（约 43.2%）。
- 敌人预热重分配为突击枪手 12、爆猎者 6、群袭者 4、伏击者 3、壁垒者 3，总数仍为 28。突击枪手金币由 4 降至 3，“弹道稳定 Mod”单体掉率由 1% 降至 0.2%。
- 新增 ADR #171，并同步 GDD v1.41、F12 / F14 工作包、Data / Locale 手册、EnemyAI / Gameplay Runtime / PoolManager 文档、测试策略、AI 导航、知识库双索引和三层 AI 记忆；历史 ADR #126 / #170 与旧会话日志保留原文。
