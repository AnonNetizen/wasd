## ADR #191：Gear Mod 手动拾取正式落地

- 用户随后明确要求把 CPU 图标正式放进游戏，并把所有 Gear Mod 奖励从即时授予改为手动拾取。`gear_mods.json` 升为 schema v3，统一配置 `gear_mod_pickup`、72 px 交互半径、来源上方 36 px 与双件左右 28 px；正式资产独立复制到 `client/assets/icons/`，不依赖 Test Lab。
- 新增池化 `GearModPickup`：40 px CPU 星窗、2 px `#68BCDD` 轮缘、`star_scale=1.8`，逻辑根节点固定，仅视觉子节点轻微悬浮 / 闪烁；无碰撞、吸附、接触拾取或超时。敌人、Mod 缓存、防御 / 生存 / 占点事件和金币祭坛都只生成已锁定 `mod_id` 的实体，金币坛两件固定左右分开且不额外消费 RNG。
- `GameplayRunLoop` 把拾取物纳入现有交互距离仲裁，每次 `interact` 只处理最近一件；成功后才调用原子授予，正常 Mod 显示名称、目标阶级和完整效果，满阶显示转化 75 金币。授予失败时实体保留。世界事件完成反馈改为“Gear Mod 已掉落”。
