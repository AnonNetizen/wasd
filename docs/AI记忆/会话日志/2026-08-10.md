# 2026-08-10 会话日志

## ADR #196：统一效果框架与本地 Gear Mod

- 用户要求把大量后续 Mod / 效果扩展建立在统一数据驱动框架上，并允许玩家本地包新增 Gear Mod。新增每局 `GameplayEffectRuntime`、`EffectPrimitiveRegistry` 与 `EffectExecutionGateway`；7 类触发、7 类条件与 10 类动作统一使用 `program_id + trigger + conditions[] + actions[] + proc_chance + internal_cooldown`，概率走 `RNG.combat`、时间走 `GameClock`，FIFO 链深上限 8、每物理帧动作预算 256。
- Skills 升 v3，以 `programs[]` 进入运行时；Gear Mod 升 v6，以可组合 `modifier / program / board_rule` components 取代旧 kind / map / grid 分支。现有属性 Mod 转为 modifier，刷怪笼转为当前模块周期 program，石头转为 `occupy_only`；运行时快照保存 ICD、周期与 action state，刷怪计划失败重试和续局均不重抽。
- 本地 manifest 升 v2：动态 Gear Mod ID 必须属于 `mod_<package_id>_` 命名空间；包只能追加 Gear Mod、官方奖励池贡献、官方敌人掉落和双语 locale，只能组合官方原语。包先独立校验，坏玩法包单独禁用；活动 Run / Replay 拒绝重载，标题新增只读 Mod 状态面板与显式重载。
- 媒体注册表支持受限 PNG / WebP / JPEG 与 Ogg Vorbis / MP3 / WAV 非循环 SFX；校验路径、文件头、解码、尺寸 / 时长 / 数量 / 总量和命名空间。缺失或损坏媒体只诊断并回退；本地 Gear Mod 可用 `codex_icon_path` 与 `placement_sfx_id`，展示媒体不进入 gameplay hash。
- Save 升 Run v19、Replay 升 v9、游戏升 v1.18；精确保存 `mod_environment[{id,version,gameplay_hash}]`。旧 Run v18 / Replay v8 与缺包、版本、玩法 hash 不匹配均保留原文件并拒绝继续 / 播放，不当作普通坏档隔离；四条黄金回放已按 v9 重录并 4/4 复跑通过。
- 遗物数据、资源池、契约、locale、测试岛入口、四平台 `/new-relic` 与任务模板全部删除，改为 `/new-gear-mod` 与“加 Gear Mod”。历史 ADR、旧会话日志、报告和历史输出保持原文；新增 ADR #196，并同步 GDD、词表、测试策略、代码文档、AI 导航、知识索引、项目记忆与工作包。
