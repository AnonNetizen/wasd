## 胶质子弹视觉选型墙

- 用户要求仅在 `output/test_lab` 制作 1280×760、3×2 的六种子弹动态选型墙，不改正式 `client`；每种同时展示完全同形的敌方红弹与玩家白弹。
- 新增泪核胶珠、十字胶籽、缺口胶环、圆头胶囊、三瓣胶冠和棱面胶矢；统一使用暗色反边、胶体外壳、深色内馅和湿润高光，只以轮廓、轴向压缩、相位及命中反应区分。
- 共享的 `TestLabBulletVfxSample` 以 `variant + palette + hit_radius` 配置，红白复用同一几何；玩家子弹按 `r=8 / 520 px/s`、敌弹按 `r=5 / 280 px/s` 展示。拖尾使用六段有界历史，重置与命中会完全清空；命中动画不创建子节点。
- 选型墙提供 `Space` 暂停、`R` 重置、`D` 判定圆、`T` 拖尾、`B` 三档背景和 `Esc` 返回索引；已加入 Test Lab 索引与 README。
- 新增专用 smoke 覆盖六个唯一候选、每种一红一白、同形异色、主体不越判定圆、敌弹红色主体占优、拖尾有界、重置无残留和命中无节点累积；固定 `0.72 s` 捕获“白弹命中 + 红弹飞行”总览 `screenshots/bullet_vfx_selection.png`，二次捕获 SHA-256 一致。
