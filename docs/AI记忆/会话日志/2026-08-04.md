## 史莱姆书本透视窗实验

- 用户明确不需要翻页，要求沿用史莱姆十字软体骨架与固定空间透视 Shader 的实现方式表现一本书；本轮新增独立 `slime_book_perspective_test.tscn`，不修改原十字实验、旧 Polygon 翻页书实验或正式 `client`。
- 原 `TestLabSlimeCross2D` 只抽取一个可覆写的静止轮廓来源，默认仍返回原 20 点十字轮廓；新 `TestLabSlimeBookPerspective` 改用左右镜像的 20 点摊开书轮廓，继续继承相同弹簧、阻尼、邻点保形、位移扩散、面积压力、动态圆角和固定 `Polygon2D + ShaderMaterial` 遮罩。
- 书本身份由顶端书脊凹口、底部书脊尖点、中央书脊线和左右页缘引导线建立；内部线条通过同一形变映射随软体移动。实现没有独立页层、翻页状态、页格或 3D 曲面，透视内容继续直接复用 `anchored_star_window.gdshader` 的 `SCREEN_UV` 固定空间星空。
- 新增专项 smoke、场景生成器、Test Lab 索引、README 和固定步进 1280×760 捕获。自动检查覆盖 20 点单轮廓、书脊点 / 页缘线数量、顶凹口、底投影、静止左右对称、页宽比例、100 点动态遮罩、Shader 资源、整体位移、左页局部响应、遮罩同步与面积保持。
- 连续两次捕获 SHA-256 均为 `A4BFD78C6EF9B0E64C10B7AAFDD6BF96D07AF238A54F9CBA906A7A9DB466A741`；左右页内部最亮 RGB 和分别为 `2.0824 / 2.0471`，透明或仅渲染单页会令捕获失败。像素探针属于自动渲染存在性验证；书本辨识度、书脊线强弱、移动时的固定空间透视读法和边缘配色按 ADR #174 待用户人工验收。

## 四节点史莱姆边圆球子弹

- 用户要求把 Shader 渐变圆球改成史莱姆式实现：用四个节点组成子弹边缘，删除高光，只让边缘与内部颜色略有区别；继续修改既有 `glow_orb_bullet_focus_test.tscn`，不新建正式 `client` 资源。
- 当前样本删除 `gradient_orb_bullet.gdshader` 与固定 `Polygon2D + ShaderMaterial` 渲染面。每颗弹建立东 / 南 / 西 / 北四个持久 `Node2D` 控制点，复用 Steamworks Slime Lab 的 centripetal Catmull-Rom 边缘思路，每段 16 个样本，共生成 64 点闭合轮廓；内部使用阵营平色，边缘使用略亮的同阵营统一色，不存在局部高光、渐变、黑边或外发光。
- 红白版本严格共享控制点几何；玩家白弹使用 `#DCEAF2 / #F6FBFF` 内外色，敌方红弹使用 `#E62935 / #FF5963` 内外色。玩家 `r=8 / 520 px/s`、敌人 `r=5 / 280 px/s`、有界拖尾、命中生命周期和判定圆保持不变。
- 专项 smoke 改为检查每样本恰好四个基数方向控制节点、64 点平滑边界、稳定节点数、内外色差、无 Shader / 高光 / 外发光及原运动 / 清理契约；确定性捕获增加红白内部与边缘像素色差门禁。最终边宽、色差、高速读法和拖尾判定误导按 ADR #174 待用户人工验收。
- 事实审查发现原“主体不越判定圆”仍读取配置半径而非四点曲线的真实结果；现改为扫描 64 个渲染边界点的最大中心距离并加半个实际边宽，使未来控制点或插值鼓出判定圆时直接失败。连续两次 1280×760 捕获 SHA-256 均为 `3CD23AE9BEF466FBF84AA62F908327EB1798F359FAE33721B1AE543DE1C1F598`；既有六候选、泪核放大与七材质 smoke 保持通过。正式 `client`、性能 probe 和黄金回放均不在本轮范围。

- 新 `TestLabSlimeApplePerspective` 复用既有可覆写 20 点单轮廓、弹簧 / 阻尼 / 邻点保形、位移扩散、面积压力、动态圆角和固定 `Polygon2D + ShaderMaterial` 遮罩；苹果以近圆果腹、顶部凹肩、短果柄和一片外伸叶子构成，果柄与叶片直接并入闭合外轮廓，没有独立视觉节点。
- 用户检查首版预览后指出叶片无法辨认。根因是首版叶片只伸到局部 `x=78`，在 30px 软轮缘和圆角平滑下读成顶部小鼓包；现重排顶部与果腹控制点，让叶尖伸到 `x=122`，用独立上缘、尖端、下缘和窄叶根形成明确右上剪影，并把 smoke 的叶片外伸下限提高到 90px，仍不增加叶脉或内部线。
