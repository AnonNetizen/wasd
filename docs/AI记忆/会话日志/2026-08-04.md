## SVG 曲线梨透视窗实验

- 用户提供 `梨.svg`，明确不再使用史莱姆软体或控制点骨架，而是直接把矢量曲线转换为实验形状。复制到 Test Lab 的 `pear_source.svg` 删除生成器 metadata，但保持原 `d` 路径和 `translate(0,512) scale(0.1,-0.1)` 坐标变换；轻量导入器支持当前来源使用的绝对 / 相对移动、直线、水平 / 垂直线、三次 Bézier 和闭合命令，并生成三个闭合 `Curve2D + Path2D` 子路径。

- `Curve2D` 的细分点只作为运行时渲染缓存，不取代权威曲线；整条矢量只做整体平移来暴露 `SCREEN_UV` 固定空间读法，不存在 `_physics_process`、弹簧、面积压力、质点或局部形变。Godot 4.7.1 的同步 `NavigationServer2D.bake_from_source_geometry_data` 用于无弃用警告地烘焙复合边框。
- 专项 smoke 确认三个闭合子路径 / Path2D、两个内部填充区、604 个边框三角形、248 个内部三角形，边框 / 内部面积比为 `1.00001 / 1.00000`，边框无 Shader、内部直接复用透视 Shader；事实审查进一步删除了与物体无关的背景网格，以源码门禁禁止成品场景新增 `draw_line()`，并把像素门禁拆成叶片 / 梨身两个独立样本组，避免梨身亮像素掩盖叶片空渲染。连续两次 1280×760 捕获 SHA-256 均为 `EDEFC88AB62BD8C79B18CE3C8DF6F093C13FC791FF50B1B82CCF3AAE81EA2783`，叶片 / 梨身内部最亮 RGB 和分别为 `0.6078 / 2.5098`；原十字、透视十字、透视书、透视苹果和 anchored-star smoke 保持通过。正式 `client`、性能 probe 与黄金回放不在本轮范围；边框粗细、梨 / 叶片辨识度及透视读法按 ADR #174 待用户人工验收。
