# 2026-07-28 会话日志

## ADR #166 局内威胁时间、敌人强化与难度标记器

- 用户确认标准难度在 12 分钟后继续增长，不设置最终上限；首版只强化敌人生命与伤害，不强化移速，敌人组合与遭遇预算留给后续。
- 新增 `difficulty_profiles.json` schema v1，`game_modes.json` 升 schema v2 并通过 `difficulty_profile_id` 引用。标准曲线每 90 秒同时包含 `0.04` 连续增长和 `0.09` 阶段跃升；伤害只取生命 coefficient 增量的 `0.48`。12:00 为生命 `2.04×`、伤害 `1.4992×`，之后继续。
- 新增模式级 `DifficultyProgression`。模块世界只在玩家不处于 `module_role_start` 时推进；开放战区立即推进；开发者测试岛关闭。底层 `GameClock` 继续驱动移动、回复、冷却、状态和 Replay tick。
- `WeaponSystem` / `SkillSystem` 接入同步 combat gate：起点房内射击不生成子弹、不消耗 `RNG.combat`；技能返回 `combat_locked`，不消耗能量或冷却。移动、冲刺、交互、回复、冷却、敌人和敌弹不受限；持续按住开火离房后可立即开火，技能需重新按键。
- 模块敌种解锁、开放战区 wave / director gating 改读威胁时间。Enemy 在真正生成时取得生命 / 伤害倍率快照；最大生命、接触伤害和远程弹丸伤害缩放，移速、攻击间隔、弹速、AI、掉落和预算不变。预警跨阶段线以生成时倍率为准，既有敌人不重算，流式卸载 / 续局保存精确倍率。
- HUD 在右上小地图下加入难度标记器，显示 `MM:SS`、威胁等级、九段中英文名称和分段进度；Lv.9 后名称保持“巢灾 / Nestfall”但等级继续增长。起点房显示难度暂停和武器 / 技能锁定；详细面板显示新生成敌人的生命 / 伤害倍率，阶段高亮遵守 reduced motion。
- Run 升至 v6，保存 `DifficultyProgression` 和每只敌人的出生倍率。旧 Run v5 无法还原起点停留时间和出生倍率，明确标记不兼容并只删除 run、保留 Meta。Replay 保持 v3，`run_end` 与黄金运行时摘要加入难度时间、等级和倍率。
- 数据、代码、HUD、本地化、ADR、GDD、Gameplay Runtime、SaveManager、Replay、WarzoneDirector、GameClock、SkillSystem、测试策略、AI 导航、知识索引和三层 AI 记忆已同步。本任务按 ADR #143 不运行 startup/performance probe 或 Profiler。
- 最终通过 contracts、data/schema、三档 lint 与自测、文档 / JSON 健康检查、Godot 4.7.1 headless editor/boot，以及 L1、runtime、save、完整 / 技术模块世界、loading、settings、actor、F9、replay、replay-input、UIManager、VFX、input、Gear Mod smoke；四条 Replay v3 golden 已重录并以运行时摘要重跑通过。
- 事实型审查未发现 P0 / P1 代码缺陷；发现的三条 P2 测试空白已补齐：开放战区立即推进与 60 秒 wave gating、暂停 Run v6 的威胁时间 / 等级 / 倍率精确 roundtrip、Enemy 接触与远程 Bullet → Combat 实际伤害链。1920×1080 中英文、长等级和 reduced motion 仍保留为人工视觉验收项；最终明细见 `docs/AI记忆/current_state.json.last_verified`。

## ADR #167 瞄准方向引导镜头

- 用户要求摄像机不再无脑把玩家始终放在正中央，而是继续 GLUED 跟随玩家并向当前瞄准方向平滑偏移；保持水平、等比缩放、无相机边界 / drag，震屏与稳定引导互不干扰。
- `camera_feedback.json` 升至 schema v3，新增必填 `aim_look`：鼠标比例 `0.30`、最大偏移 `240 px`、死区 `32 px`、平滑时间常数 `0.18 s`。Python 与 GDScript DataLoader 同步校验缺字段、类型和取值范围。
- `GameplayCameraController` 保持 `configure()` 签名和对局级 Rig：开局 / 重绑从零偏移开始，首次有效 aim 后才引导；鼠标按光标到玩家实际屏幕位置的距离计算，键盘、手柄与 Replay 使用归一化最终 aim 的最大偏移，松开后保持方向；指数平滑与帧率无关，暂停冻结。新增 `current_look_offset()` 只读诊断。
- `Player.set_camera_look_offset()` 接收稳定引导偏移，使鼠标瞄准从“固定屏幕中心”改为“玩家实际屏幕位置”；`Camera2D.offset` 震屏噪声不参与换算。固定版本 Phantom Camera 的 GLUED 更新路径不消费其导出 `follow_offset`，项目适配层在 Host 更新后把同一稳定偏移镜像到真实 Camera 位置，不新增代理节点、不修改插件源码。
- `gameplay.screen_shake` 关闭时只停止两个 emitter 并清零噪声 offset，不清理引导；`gameplay.reduced_motion` 当前不影响摄像机，删除另案处理。Run 保持 v6、Replay 保持 v3，不新增设置或相机快照字段，震屏 profile 数和数据指纹结构不变。
- Runtime smoke 覆盖开局 / 重绑居中、鼠标公式与静止保持、玩家实际屏幕位置、键盘 / 手柄 / Replay 最大偏移与保持、输入源切换、暂停冻结恢复、震屏隔离和固定插件 GLUED 画面桥；schema 回归覆盖缺失 / 非法 `aim_look`。
- 新增 ADR #167，并同步 GDD v1.37、Gameplay Runtime、Phantom Camera、数据手册、测试策略、README、IP / 术语、AI 导航、知识索引、四平台规则和三层 AI 记忆；历史 ADR 与旧会话日志未回写。
- 最终通过 `validate_data`、DataLoader schema、三档 lint、JSON / 文档健康、`git diff --check`、actor / input / settings / runtime / replay-input smoke、Godot 4.7.1 headless editor / boot、完整 pre-commit；四条既有 Replay v3 黄金回放只重跑、不重录，玩法摘要未变化。本任务未运行 performance probe。
- 事实型 review 发现并修复两处 P2：菜单阶段遗留的鼠标位置可能在重绑后立即启动引导；`max_offset_px` 的运行时校验与“负值非法、零值允许”文档契约不一致。补充回归后无剩余 P0 / P1 / P2 发现。1920×1080 八方向、鼠标边缘、真实手柄切换、地图边缘、暂停和震屏可读性保留为人工验收项。
