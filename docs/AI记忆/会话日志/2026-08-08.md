## 玩家移速约 30% 调整

- 用户要求把玩家移速稍微加快约 30%。数据层将 `client/data/player.json` 默认 `move_speed` 从 240 调到 312，`client/data/characters.json` 两个现有角色从 230 / 250 调到 300 / 325，并同步 `client/data/README.md` 示例。
- 这是一项已有数值字段的小幅调参，正确路径应是修改数据、运行 `validate_data`、交付前对本次文件跑一次 pre-commit，并把实际操控手感留给用户做 L5 人工验收。

## ADR #192：风险分层验证与 Godot 串行执行

- 本轮实际执行错误地继承了 8 月 7 日 Gear Mod 大型变更的重型验证习惯：先后重复跑 schema / pre-commit，又把 headless boot 与 runtime smoke 指向同一个 `client/` 并发启动。两条命令都超时并留下 Python / Godot 子进程，延长了一个本应很快完成的调参任务。
- 随后的已删除脚本旧路径和缺失 SVG 导入产物来自本机 `.godot` / UID / import 缓存，并非本次移速数据改坏源码。排障时只终止本轮创建的精确进程，备份精确缓存文件后串行 import，最小 boot / runtime 才恢复通过。这个绕路说明同项目 Godot 命令不能共享缓存并发，也不能根据陈旧缓存报错贸然修改源码。
- 四条现有黄金回放不包含能验证准确移速的稳定玩家坐标样本；重录只产生 tick / time / hash 文本噪声，没有为“移速增加 30%”提供新证据，因此全部噪声 diff 已撤销。以后必须先审查 replay 输入与稳定摘要是否覆盖目标变量，再决定是否运行或更新基线。
- ADR #192 固化五条约束：每次按当前任务重新分级；简单已有数值调参走 L0 快路径；昂贵门禁去重；共享项目缓存 / 用户目录的 Godot 命令默认串行且超时先清理本次子进程；golden 只在真实覆盖且稳定语义或 data fingerprint 改变时重录，纯时间 / tick / hash 噪声不入库。
- 同步更新 `docs/测试策略.md`、`docs/CICD规划.md`、`docs/AI导航.md`、`docs/代码文档规范.md`、`docs/AI知识库索引.md`、调数值模板、实时验证回路、工具适配指南、ADR、项目记忆与机器状态。没有改变 hook / CI 配置、知识库路径、AGENTS 开工入口或平台核心规则，因此不修改 `docs/_kb_index.json`、`AGENTS.md` 及平台入口副本。
- 本次文档同步只运行 JSON 解析与 file-scoped pre-commit；不再运行 Godot boot、runtime、replay、性能测试或任何人工验收。移速手感仍待用户实际试玩确认。

## ADR #193：完全删除 Gear Mod 等级

- 用户明确要求删除 Gear Mod 等级机制且不保留升级接口。`gear_mods.json` 升至 schema v4，以固定 `{stat,type,value}` modifiers 取代 `max_rank` / `rank_modifiers`，并删除 `overflow_gold`；旧等级字段由 Godot 与 Python 双端校验器精确拒绝。固定效果采用旧第 2 档：伤害 ×1.20、后坐力和扩散上限 ×0.80。
- `GameplayRunLoop` 改用可重复的 `mod_ids` 独立实例数组；每次成功拾取只追加一份，同 id 多份逐份乘算，存档、应用和结算都使用排序副本。结果摘要按同一 Mod ID 聚合数量后以本地化名称显示，不把数量解释成等级。
- 删除 `GearModSystem` 的等级、最大等级、升级预览、溢出金币与批量授予接口；HUD、拾取提示、结果页、Codex、locale、契约和测试岛同步删除等级 / 满阶 / 溢出表述。Debug Test Arena 配置升 v3、旧 v2 重置；配置规范化会按 `mod_id` 去重，避免手改配置形成隐藏数量入口。
- Meta 保持 v4 且不保存局内实例；Run 升 v17，旧 v16 及更早版本只标记不兼容并由正式启动删除 Run，不转换 ranks、不影响 Meta。Replay 文件与 recording 升 v7并精确拒绝 v6；游戏版本升 v1.16。Replay 指纹纳入规范化 Gear Mod schema、拾取配置、奖励池顺序、固定效果、默认开放语义和掉落表，排除名称、描述、稀有度、图标及本地化展示字段。
- 事实审查发现并修复四项：测试岛重复 id 可形成隐藏数量入口；结果页曾按 `name_key` 错误合并不同 Mod；Replay 指纹误纳入仅供展示的 `rarity`；重录产生两处 decision time 噪声。修复后无未解决的 P0 / P1 / P2 行为或契约问题。
