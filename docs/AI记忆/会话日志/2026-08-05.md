## 双涡旋史莱姆玩家阶段一人工门禁

- 用户要求按既定两阶段计划实施玩家史莱姆改造；本轮严格停在阶段一，只新增独立 Test Lab 原型、自动门禁和预览，不修改正式 `client/`，也不创建待正式方案批准后才成立的 ADR #183。
- 新 `TestLabPlayerSlimeFusion` 固定使用 20 个环形控制点，每个控制点以 5 次有界二次曲线采样生成 100 点共享边界；`Body / Outline / WetRim` 只更新既有节点。速度、径向 / 切向位移、邻点速度与位移连续性、面积压力和最终中心线半径均受限，最宽暗轮缘计入后不得越出 25 px 判定圆。开火与受击冲击只分散到连续 5 点，避免单点尖刺。
- 新 `player_slime_dual_vortex.gdshader` 只从角色本地 `VERTEX` 坐标取样，不使用 `SCREEN_UV`。冷静 / 愤怒双方 primary 形成 50/50 顺时针 / 逆时针两股气；经用户后续收敛，每个碎片只向史莱姆视觉提供一个 primary，内部轮缘、外部 Outline 和中心到 38 px 枪口的三段渐隐短束均使用当前主碎片 primary。没有眼睛、箭头或长瞄准线。
- `player_slime_fusion_test.tscn` 同屏提供移动 / 开火 / 受击的实战 `r=25` 样本、`r=12` 正式史莱姆子弹尺寸参照，以及“冷静主 / 愤怒副”“愤怒主 / 冷静副”两份 4.35× 放大预览。WASD / 方向键移动，左键或 `F` 开火，`H` 受击，`X` 交换实际样本主副，`Space` 暂停，`T` 切自动演示，`R` 复位。
- 外轮缘加宽后的专项 smoke 720 帧连续移动 / 开火 / 受击压力结果为：面积比 `0.9316–1.0174`、最大最终轮缘 `24.8446 px`、最大边界转角 `5.703°`、最大邻点位移差 `1.067 px`。20 / 100 点拓扑、3 px 暗边 / 1 px 湿润亮边、双方 primary uniform、角色本地反向流、连续五点冲击、38 px 光束、暂停冻结、主副交换、节点 / 材质不增长和固定步进几何一致性全部通过。
- primary-only 配色收敛并完成 Shader 重新导入后，连续两次 1280×760 固定步进捕获 SHA-256 均为 `BD4C5BCF436E6374FAE3B34CE862CED2C66E14D7FDA9FF471E809F355E8CCF03`；事实审查把探针从光束穿过的中心移到常驻光束之外，两份放大样本的体内像素均确认非空渲染，避免 Body 透明时被光束误判。该探针只属于机器渲染存在性验证，不代替视觉判断。
- 当前人工门禁保持“待用户人工验收”：双涡旋是否读成两股气、主副交换是否可辨、短束方向是否清楚、连续形变是否无突出节点、实战玩家是否与 `r=12` 子弹混淆。用户明确确认前，不接正式 Player、数据、场景、ActorPresentationController 或黄金回放；未运行性能 probe。

- 用户随后要求把边加宽；Test Lab 暗色 Outline 由 `2.0 px` 增至 `3.0 px`，湿润 WetRim 由 `0.75 px` 增至 `1.0 px`。求解器按新 Outline 半宽自动收紧中心线，最外缘仍不越过 `r=25` 判定圆；正式 `client/` 仍未修改。
